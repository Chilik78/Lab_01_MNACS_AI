## Описание модулей

### `stat_u.py` — Статистика задач Codeforces

Скрипт обращается к публичному API Codeforces (`problemset.problems`), получает список задач и формирует статистику:

- **По сложности (рейтингу):** подсчитывается количество задач для каждого рейтинга, результат сортируется по возрастанию.
- **По тегам:** подсчитывается количество задач для каждого тега, результат сортируется по убыванию популярности.

**Особенности реализации:**
- Обработка ошибок при HTTP-запросе (try/except).
- Проверка корректности ответа (статус 200 и тип `application/json`).
- Использование словарей для накопления статистики.

**Запуск:**
```bash
python stat_u.py
```

### `quad_eq_ws.py` — Веб-сервис решения квадратных уравнений

Веб-приложение на **Flask**, реализующее решение квадратного уравнения вида `ax² + bx + c = 0`.

**Функциональность:**
- Функция `quad_eq_solve(a, b, c)` вычисляет дискриминант `D = b² − 4ac` и возвращает список корней.
- Маршрут `/` (GET) — отображает форму ввода коэффициентов.
- Маршрут `/quad_eq` (POST) — принимает коэффициенты и режим отображения, выполняет вычисления и возвращает результат на страницу.

**Режимы отображения:**
- `roots` — только корни уравнения;
- `discriminant` — корни и значение дискриминанта.

**Запуск:**
```bash
python quad_eq_ws.py
```
Приложение будет доступно по адресу `http://127.0.0.1:5000/`.

### `cf_rate.py` — API среднего ранга пользователя Codeforces

REST-сервис на **FastAPI**, возвращающий средний ранг пользователя Codeforces по всем его выступлениям в контестах.

**Эндпоинт:**
```
GET /cf_rate/{cf_id}
```

**Логика работы:**
1. Запрос к `https://codeforces.com/api/user.rating?handle={cf_id}`.
2. Извлечение поля `rank` из каждого контеста.
3. Вычисление среднего значения через `statistics.mean`.
4. При ошибке возвращается строка `"0"`.

**Запуск:**
```bash
python cf_rate.py
```
Сервер запускается на `http://0.0.0.0:8001`.  
Документация OpenAPI: `http://localhost:8001/docs`.

---

### `dish.py` — API поиска рецептов

REST-сервис на **FastAPI**, работающий с внешним API [TheMealDB](https://www.themealdb.com/api.php).

**Эндпоинт:**
```
GET /search?s=<название>     # поиск по названию блюда
GET /search?f=<буква>        # поиск по первой букве
```

**Логика работы:**
- Формируется URL в зависимости от переданного параметра.
- Выполняется запрос к TheMealDB.
- Результат преобразуется в список словарей вида `{"idMeal": "strMeal"}`.

**Запуск:**
```bash
python dish.py
```
Сервер запускается на `http://0.0.0.0:8001`.  
Документация OpenAPI: `http://localhost:8001/docs`.

---

### `templates/index.html` — Шаблон формы квадратного уравнения

HTML-шаблон с использованием шаблонизатора **Jinja2** (встроен во Flask). Располагается в папке `templates/`.

**Особенности:**
- Адаптивная вёрстка (flexbox, медиа-запросы).
- Стилизация через встроенный CSS (градиенты, анимации, тени).
- Форма с тремя полями ввода коэффициентов `a`, `b`, `c`.
- Переключатели режима отображения результата (радиокнопки).
- Блок вывода результатов с условным отображением дискриминанта.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone <url-репозитория>
cd <папка-проекта>
```

### 2. Создание виртуального окружения (рекомендуется)

```bash

source venv/bin/activate
```

